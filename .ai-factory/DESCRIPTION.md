# Приложение «Библия» — учебный проект-портфолио

## Обзор

Офлайн-приложение для чтения Библии на Android. Две цели: практическое освоение мобильной разработки (React Native + Expo) разработчиком с full-stack бэкграундом и публикация готового продукта в Google Play как главного аргумента на собеседованиях. Тексты Библии и сноски хранятся локально, приложение полностью работает без сервера.

## Основные функции

- Чтение: выбор книги → главы → список стихов (FlatList, сотни глав и тысячи стихов, подгрузка порциями)
- Навигация между главами, переходы по ссылкам на стихи
- Полнотекстовый поиск по стихам (SQLite FTS5)
- Закладки и история чтения
- Сноски к стихам
- Настройки: размер шрифта, тема (светлая/тёмная)
- Релиз: сборка через EAS Build, публикация в Google Play

## Технологический стек

- **Язык:** TypeScript (strict mode с первого дня)
- **Фреймворк:** React Native + Expo (актуальный SDK)
- **Навигация:** expo-router (файловая маршрутизация)
- **База данных:** expo-sqlite (SQLite + FTS5, база поставляется в ассетах приложения)
- **Состояние:** React hooks + Context; без тяжёлых стейт-менеджеров на старте (YAGNI)
- **Сборка/релиз:** EAS Build, Google Play Console
- **Контроль версий:** git + GitHub (репозиторий создаётся вместе с каркасом)

## Архитектурные заметки

- Офлайн-first: в MVP нет сетевых вызовов, всё работает из локальной базы
- Слоистая структура: `app/` (экраны и роуты) → `features/` (доменная логика) → `db/` (доступ к SQLite) → `components/` (общие UI-компоненты)
- Доступ к данным изолирован в репозиториях: экраны не знают про SQL, только про функции-обёртки
- Дизайн-токены (цвета, отступы, типографика) собраны в одном модуле темы

Подробные архитектурные соглашения — в `.ai-factory/ARCHITECTURE.md`.

## Нефункциональные требования

- **Язык кода:** английский; комментарии в коде не пишутся
- **Производительность:** ленивая подгрузка стихов, мемоизация элементов списков
- **Обработка ошибок:** guard clauses и ранние возвраты; Error Boundary на уровне корня приложения
- **Логирование:** console.* только в dev-сборках
- **Безопасность:** никаких секретов в коде; сборочные креды — через EAS secrets
