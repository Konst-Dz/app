# Базовые правила проекта

> Проект пуст, правила сформулированы под выбранный стек (TypeScript + React Native + Expo) и предпочтения разработчика. По мере появления кода дополняйте реальными конвенциями.

## Соглашения об именовании

- Файлы React-компонентов: PascalCase (`VerseList.tsx`)
- Прочие TS-модули: camelCase (`bibleRepository.ts`)
- Переменные и функции: camelCase
- Типы и интерфейсы: PascalCase, без префикса `I`
- Константы модуля: UPPER_SNAKE_CASE
- Переменные окружения/конфиги Expo: UPPER_SNAKE_CASE (`EXPO_PUBLIC_*`)

## Структура модулей

- `app/` — экраны и маршруты expo-router, только композиция
- `features/` — доменная логика по фичам (поиск, закладки, настройки)
- `db/` — схема, миграции и доступ к SQLite
- `components/` — переиспользуемые UI-компоненты без доменной логики
- `theme/` — дизайн-токены: цвета, отступы, типографика

## Обработка ошибок

- Guard clauses и ранние возвраты вместо глубокой вложенности
- Ошибки БД и некорректный ввод обрабатываются явно, исключения не «глотать»
- Error Boundary на уровне корня приложения

## Control Flow

- Предпочитать плоский читаемый поток исполнения глубокой вложенности: guard clauses, ранние `return`/`continue`, небольшие именованные функции-хелперы
- Граничные случаи отсекать в начале функции, чтобы основной путь оставался видимым

## Логирование

- `console.*` только в dev-сборках; в проде логов нет

## Общие принципы

- Clean code, SOLID, DRY, KISS, YAGNI
- Язык кода — английский; комментарии в коде не пишутся
