# Дорожная карта проекта

> Офлайн-приложение для чтения Библии на Android — портфолио-проект: от каркаса Expo до публикации в Google Play.

## Этапы

- [ ] **Каркас Expo-проекта** — init Expo с TypeScript strict, expo-router, структура папок по архитектуре, тема, git init и репозиторий на GitHub. Результат: проект открывается в Expo Go на телефоне.
- [ ] **База данных SQLite** — схема (книги, главы, стихи, сноски), FTS5-таблицы, bundled-база в ассетах, доступ через `db/`. Результат: данные читаются из приложения.
- [ ] **Экран чтения** — выбор книги → глава → стихи (FlatList), переходы между главами, тонкие маршруты + хуки + api по архитектуре. Результат: основной сценарий работает.
- [ ] **Поиск** — FTS-запросы, экран результатов, подсветка совпадений. Результат: быстрый полнотекстовый поиск по стихам.
- [ ] **Закладки и история чтения** — добавление/удаление, экран закладок, продолжение с последнего места. Результат: состояние пользователя сохраняется между сессиями.
- [ ] **Сноски к стихам** — просмотр сносок из стиха. Результат: контент Библии отображается полностью.
- [ ] **Настройки и тема** — размер шрифта, светлая/тёмная тема через Context. Результат: приложение персонализируется.
- [ ] **Стабилизация** — оптимизация списков по скиллам Vercel/Callstack, Error Boundary, тесты (Jest + React Native Testing Library). Результат: приложение не стыдно показывать на собеседовании.
- [ ] **Сборка релиза** — EAS Build, иконка и сплэш, подписание, версионирование. Результат: APK/AAB собирается в облаке по команде.
- [ ] **Публикация в Google Play** — аккаунт разработчика, внутреннее тестирование, продакшн-релиз, полировка README на GitHub. Результат: главный аргумент для собеседований готов.
